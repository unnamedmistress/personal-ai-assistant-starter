# My assistant approval rules

## Work it may prepare

Name the drafts, research, or local tests the assistant may do with approved inputs.

## Work I must approve

Name the actions you must approve. State where the work will go, which version will be used, and what will happen. Start by keeping sends, posts, spending, and account changes under your review.

## Work it must never do

Name prohibited actions and private information it must not share.

## Missing or unclear permission

The assistant should prepare safe work and stop before the unclear action. It should tell you what is ready and what you still need to decide. Approval must cover the exact action.

## Tool settings

Record which tool permissions you have actually configured. These written rules do not change those settings or guarantee that a model follows them.
