Try three failure exercises

The old price

An answer uses an old note even though the catalog marks a newer source as current. Check which source and price the answer should use.

The missing delivery

A record says the task is complete but has no delivery evidence. Check what is actually known before calling it finished.

The premature rule

One attempt becomes a proposed lasting rule. Check the separate evidence and owner review before accepting it.

Each exercise has a flawed fixture and a corrected fixture. All records are fictional. A corrected delivery fixture is still synthetic; no message is sent.

Run the local checks

Download the repository, extract it, and open a terminal in that folder. With Python 3.11 or newer installed, run:

python run_examples.py
python -m unittest discover -s tests -v

These commands use no AI model, network connection, API key, or third-party Python package. If you try the optional prompts with an AI assistant, that tool may require a subscription or charge for usage.

Know what a passing check means

A passing fixture check means the sample code matched its expected result. It does not prove that a real assistant followed instructions, a source is true, or a delivery occurred.

Written guidance, software-enforced rules, and evidence from a real service each play a different part. This package teaches that distinction. It does not connect permissions to your accounts or certify an AI system as safe.

Questions about personal AI assistant setup

How do I check an AI assistant’s memory?

Give it an old note and a clearly marked current source. Ask it to name the source it used. Compare the answer with that source yourself, and leave unresolved conflicts marked as unknown.

How do I know a task is finished?

Define the result before the assistant starts. A draft proves a draft exists. If approved delivery is part of the task, check separate evidence that the intended version reached the intended destination.

How do I set approval rules?

Record what the assistant may prepare and what needs your exact approval. Check your tool settings too. Written instructions do not change account permissions.

Is this a new AI platform?

No. It is a small set of templates and fictional exercises you can adapt. The code checks local records and does not run an AI assistant.
