# My assistant trial

## Setup

Record the date, tool, model if known, relevant settings, and permission limits. Use fictional inputs.

## Task and expected result

Save the exact input and expected behavior before the test. State which part needs human judgment.

## First answer

Save the assistant’s actual first answer. Do not rewrite it to match the expected result.

## Check

Record pass, fail, or unknown for this task, with the evidence and reviewer. Note any correction separately.

## Limits

Describe what was not checked. One result does not establish reliability on other tasks, tools, or versions.
