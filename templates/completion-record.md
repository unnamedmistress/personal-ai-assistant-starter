# My completion record

## Requested result

Describe the result you asked for. Name where it should go if a send was part of the task.

## What changed

Link to the artifact and record its version. Distinguish prepared, approved, and delivered work.

## Evidence checked

Name the source of proof, what it shows, and when you checked it. The assistant’s own claim is not outside proof.

## Current state

Choose the state that fits your work. Use “complete and verified” when all needed checks pass. Use “complete locally, live verification pending” when the local work is done but a live check remains. Use “blocked by external dependency” when something outside your control prevents progress. Use “draft awaiting approval” when review is needed. Use “failed and corrected” when you fixed a failure. Use “failed, workaround unavailable” when the failure remains. State what is still unknown.

## Next action

Record what remains, who can do it, and the evidence needed to close it. If nothing remains for the requested scope, say so.
