# Related work and sources

Personal AI systems already exist. Daniel Miessler’s [LifeOS](https://github.com/danielmiessler/LifeOS) is one public example. This starter does not claim to invent context, skills, or memory. It does not include code from that project.

[LangGraph persistence](https://docs.langchain.com/oss/python/langgraph/persistence) covers saved state, human review, and ways to resume work. It does much more than the sample checks here.

Simon Willison’s [agentic manual testing](https://simonwillison.net/guides/agentic-engineering-patterns/agentic-manual-testing/) discusses how to test code. These examples use a small set of checks. He has not reviewed or endorsed this package.

Ethan Mollick writes about [the jagged AI frontier](https://www.oneusefulthing.org/p/the-shape-of-ai-jaggedness-bottlenecks). AI can do one task well and fail at another. Keep each result tied to the task you checked.

I built these forms from the rules in my own My AI Evolution OS. The private system and its business records are not included. I have not measured time saved, sales gained, or a change in error rates for this package.

Sources checked September 21, 2026. These links give context. They do not mean the authors endorse this project or that their tools were tested with it.
