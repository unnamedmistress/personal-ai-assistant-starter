# Support and contributions

Found a bug in an example or a problem in the guide? Open a GitHub issue. Use made-up data. Name the file and command you used. Say what you expected and what happened. Never post passwords, private prompts, client data, or real send records.

For a code change, run `python -m unittest discover -s tests -v` and `python run_examples.py`. Explain what changed and what the tests prove. Keep the package small. Do not add a need for paid tools.

There is no set response time for issues. This free package does not include custom setup or ongoing help for your business. You can choose paid coaching if you want that help.
