# Security and privacy

This package checks made-up records on your own computer. It does not ask for passwords, use the network, send messages, or call an AI model. A passing test does not prove that a system is safe.

If you find a security flaw, look for **Report a vulnerability** on the GitHub Security tab. Use that private report if it is available. If it is not, use the contact route on [My AI Evolution](https://www.myaievolution.com/). Describe the concern without sending secrets or private data. Do not post the flaw in a public issue.

Read changes before you run code you download. Keep your real work in a private folder outside this project.
