# My source map

Copy the section below for each fact that matters to your workflow.

## Fact or topic

Name the fact, such as the approved service price or current project deadline.

## Current source

Record the file or link, version or date, owner, and when you last checked it.

## Older sources

Name any old notes that could be confused with the current source. Mark why they are superseded.

## Check again when

Record the event or review date that would require a fresh check. If sources conflict, leave the fact unresolved until the owner or source evidence settles it.
